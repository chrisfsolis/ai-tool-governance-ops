# Future Enhancements

This demo is intentionally lightweight, but it can scale into a real governance operation with:

- SSO/RBAC for requester, reviewer, approver, and admin roles.
- Vendor risk API integration for third-party risk status and security questionnaires.
- Jira/ServiceNow approval routing for operational workflow management.
- Azure OpenAI or OpenAI usage tracking for model consumption and chargeback.
- Cost dashboards with budget thresholds, anomaly alerts, and owner attribution.
- SOC 2 / ISO 27001 evidence export for audits and control testing.
- NIST AI RMF / ISO 42001 control mapping for AI governance alignment.
- Exception review workflow with expiration dates and compensating controls.
- Slack approval notifications for reviewers and business owners.
- Database backend for durable request history and reporting.
